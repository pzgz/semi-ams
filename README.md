# SEMI-AMS 复刻固件

ESP-12S（ESP8266）控制板的开源复刻固件。完整的需求、设计，以及在 Mac 上编译、烧录、测试的步骤，见 [`docs/SEMI-AMS固件文档.md`](docs/SEMI-AMS固件文档.md)；拓竹打印机 MQTT 消息的实测整理见 [`docs/拓竹MQTT消息参考.md`](docs/拓竹MQTT消息参考.md)；多台 SEMI-AMS 协同的方案（待实施）见 [`docs/多台SEMI-AMS协同方案.md`](docs/多台SEMI-AMS协同方案.md)。浏览器版是同目录下的 `.html` 文件（`python3 docs/build_html.py` 生成）。功能对照原厂"远程控制版本（支持 MQTT）"（不含 TPU 助力），沿用原来的配网方式和点灯 Blinker App 界面。同时修掉了原固件"磁铁到位却检测不到，要拿开再靠近"的问题，原因分析见文档 1.3 节。

## 和原固件相比

| | 原固件 | 本固件 |
|---|---|---|
| 霍尔、微动开关 | 中断 + 边沿判断，漏一个边沿就会卡住 | 每 10ms 按电平判断，错过一次下个周期自动纠正 |
| 电机控制时机 | 和网络代码在同一个循环里 | 独立的 10ms 系统定时器，连点灯服务器卡住时也能及时停电机 |
| 异常保护 | — | 吸入、补料、退料都有超时，超时自动进入紧急停止 |
| 调参 | 改代码重新编译 | 设备网页或串口直接改，保存在 Flash 里 |
| 调试 | — | 网页上可以点动电机、查看传感器状态和日志；串口有命令行 |

## 功能

- **自动吸入**：从进料口插入耗材，0.5 秒后电机正转把耗材吸入，到就绪开关后停止。如果就绪开关没触发，改用 FULL 霍尔判断（和原固件一样）。
- **黑色按钮（Start/Stop）**：
  - 就绪时按一下，进入打印状态。先一直送料，直到缓冲器满。
  - 打印中，缓冲器空（EMPTY）就补料，满（FULL）就停。
  - 打印中再按一下，开始自动退料。电机反转，耗材一退过就绪开关就停，尖端留在齿轮里、耗材留在进料口（"已退料"），下次按一下就能吸回去。
  - 已退料时按一下，先把耗材吸回就绪位置，然后直接进入打印状态送料。下次打印只要按一次。
  - 吸料过程中按一下，吸料完成后直接开始打印。
- **红色按钮（Emergency）**：任何状态下按一下都立即停机，再按一下恢复到之前的状态。
- **长按任意键 3 秒后松开**：重启。蓝灯急闪表示已经到时间，可以松开了。
- **运行满 7 天自动重启**：只在空闲时（无耗材、耗材就绪或已退料）执行。
- **点灯 Blinker 远程控制**：控件和原厂的 `app控制界面配置.txt` 一致，原来的 App 界面不用改。
- **拓竹打印机联动（MQTT）**：打印机用外置料盘开始打印时自动送料；打印结束后在打印机上退料，进料器等打印机把耗材退出来后自动退料。打印前后只需要操作打印机。设置方法见下面的"拓竹打印机联动"。
- **不做的部分**：TPU 助力。

### 状态

| 状态 | 电机 | 进入条件 |
|---|---|---|
| 无耗材 | 停 | 上电时没有耗材、耗材被完全抽出 |
| 耗材吸入中 | 正转（吸入速度） | 进料口插入耗材 0.5 秒后；或已退料时按黑色按钮 |
| 耗材就绪 | 停 | 就绪开关触发，或吸入时 FULL 霍尔触发 |
| 打印中 | EMPTY 时正转补料，FULL 时停 | 就绪时按黑色按钮；或按钮触发的吸料完成后；或打印机用外置料盘开始打印 |
| 退料中 | 反转（退料速度） | 打印中按黑色按钮，或打印机退料。退料中再按一次：取消退料，回到打印中继续送料 |
| 已退料 | 停 | 退料完成（耗材留在进料口）；上电时只有进料口有耗材；就绪后耗材被往外抽过就绪开关 |
| 紧急停止 | 停 | 按红色按钮，或吸入/补料/退料超时 |

用户手动往外抽耗材时，不会被电机吸回去：耗材离开就绪开关后进入"已退料"，电机不动；完全抽出后再插入，才会自动吸入。

如果就绪开关坏了（退料过程中一直没触发），退料会一直退到耗材离开进料口，避免耗材留在去打印机的管子里。

## 引脚（按 Netlist_Schematic2 核对）

| GPIO | 用途 | 电平 |
|---|---|---|
| 12 | U11 EMPTY 霍尔（DRV5032FA） | 低 = 缓冲器空 |
| 13 | U12 FULL 霍尔 | 低 = 缓冲器满 |
| 4 | U13 进料口微动开关 | 低 = 有耗材（内部上拉） |
| 5 | U14 就绪微动开关 | 低 = 就绪。这个脚同时驱动缺料红灯，固件不能把它设为输出 |
| 0 | 黑色按钮 START-STOP | 按下为低 |
| 15 | 红色按钮 EMERGENCY | 按下为高 |
| 14 / 16 | DRV8870 IN1 / IN2 | 慢衰减 PWM，5kHz |
| 2 | 板载蓝灯 | 低电平亮 |

## 第一次使用

### 1. 先备份原固件（重要）

原固件没有源码，备份下来以后随时可以恢复。接线方式和《烧录教程》一样，板子要接上电源：

```bash
pip install esptool
esptool.py --port /dev/cu.wchusbserialXXXX --baud 921600 read_flash 0 0x400000 原厂固件备份.bin
```

恢复时执行：`esptool.py --port ... write_flash 0 原厂固件备份.bin`。也可以直接用 NodeMCU PyFlasher 刷回 `~/SynologyDrive/3D打印/20260819_semi-ams/` 里原来的 `.bin` 文件。

### 2. 编译和烧录

安装 VS Code 和 PlatformIO 插件，打开本目录，然后执行：

```bash
pio run                  # 编译
pio run -t upload        # 串口烧录（CH343P，EN 接 RTS、DTR 接 GPIO0，会自动进入下载模式）
pio device monitor       # 查看日志，115200
```

第一次编译会自动下载 ESP8266 工具链和依赖库（点灯 Blinker、WiFiManager）。

### 3. 配网

和原厂教程一样：

- 上电后先尝试连接之前的 WiFi，此时蓝灯**慢闪**。
- 连不上或从没配过网时，会打开名为 **SEMI-AMS** 的热点，蓝灯**快闪**。手机连上热点后会弹出配置页（或者手动打开 192.168.4.1），选择 WiFi、输入密码，再填 **Blinker Secret**（点灯密钥），点 save。
- 连上 WiFi 后蓝灯**常亮**。
- 已经配过网、只是暂时连不上时（比如停电后路由器还没启动），先不开热点，在后台重连。3 分钟后仍连不上，才打开 SEMI-AMS 热点 5 分钟，之后继续后台重连。
- 配网期间按键和送料都照常工作。

点灯 App 的设置和原厂教程一样：添加独立设备，选网络接入，把设备的密钥（Secret Key）填到上面配网页面的 Blinker Secret 里；然后进入设备页面的界面配置，把下面这一整段粘贴进去保存。不用 App 的话，密钥可以留空。

### 4. 调试电机（建议按顺序做）

打开设备网页 `http://设备IP/`。IP 可以在点灯 App 的 IP 控件、串口日志或路由器里找到。

1. **确认方向**：在"无耗材""耗材就绪"或"已退料"状态下点"正转 2 秒"，看耗材是不是往打印机方向走。如果方向反了，把"电机方向反转"改成 1 后保存。
2. **调速度**：吸入、补料、退料三个速度分别调整，范围 10–100%，"不要太快、够打印机用就行"。补料速度要明显大于打印机的耗材消耗速度。
3. **调超时**：根据 PTFE 管长度调整"开始打印首次送料超时"和"退料超时"。

同样的操作也可以在串口完成，输入 `help` 查看命令，例如：

```
jog f 50 2000        正转 50% 2 秒
set feed_speed 55    修改补料速度并保存
status               查看状态和全部参数
```

### 5. 拓竹打印机联动（MQTT，可选）

1. 在打印机屏幕的设置里找到 **IP 地址**、**访问码**（局域网 / 网络页面）和 **序列号**（设备信息页面；Bambu Handy 和 Studio 的设备信息里也能看到）。打印机可以保持连接拓竹云，不需要打开"仅局域网"或开发者模式。建议在路由器里给打印机固定 IP。
   填之前可以先在 Mac 上验证一下（只用 Python 自带的库，不用装东西）：`python3 tools/bambu_listen.py --ip 打印机IP --sn 序列号 --code 访问码`。显示"登录结果：成功""订阅…：成功"就说明这三项都对，之后会显示打印机发来的关键字段变化，原始消息存进 `bambu_log_*.jsonl`，按 Ctrl+C 停止。
2. 打开设备网页，在"拓竹打印机（MQTT）"里填写 IP、序列号、访问码，勾选"启用"后保存。"响应进料""响应退料"默认都勾着。
3. "连接"一行显示"已连接"就好了，"打印机"一行会显示打印机的状态。点灯 App 里的 MQTT 按钮也可以开关这个功能，按钮文字显示连接状态。

自动动作：
- **开始打印**：打印机回报开始打印、并且用的是外置料盘时，进料器进入"打印中"并送料（已退料时先吸料）。用 AMS 料盘打印时不动。
- **退料**：在打印机上退料后，进料器先等打印机切断、回抽耗材，打印机提示"请从挤出机拔出外置料盘的耗材"（错误码 0x07FFC003）时马上退料，相当于替你把耗材拔出来；这样不会和打印机的挤出机对拉。等不到提示时最多等 `mqtt_unload_wait_s`（默认 120 秒）。打印机空闲时，它的耗材传感器从"有"变"无"也会触发退料。

串口也可以设置：`mqtt ip 192.168.1.50`、`mqtt sn 序列号`、`mqtt code 访问码`、`mqtt on`、`mqtt load on|off`、`mqtt unload on|off`，`mqtt` 查看状态。

**几台 SEMI-AMS 接同一台打印机时**：每台都开着 MQTT 的话，开始打印时会一起送料（自动选择哪一台还没做）。这次不用的那几台在网页上取消"响应进料"（或 `mqtt load off`），只留要用的那台。退料不用改，只有正在"打印中"的那台会退。也可以几台都取消"响应进料"，打印前在要用的那台上按一下黑色按钮开始送料，打完在打印机上退料时它会自动退。

**注意**：这些判断规则已经在 P2S 上实测过外置料盘的完整流程（在打印机屏幕上退料）。其它打印机型号、或从 Studio / App 发起退料等情况还没测；打印机发来的关键信息（状态、阶段、耗材传感器、料盘、命令）都会写进日志，不对的地方看日志排查。

## 可调参数（默认值）

| 参数 | 默认 | 说明 |
|---|---|---|
| load_speed | 50% | 吸入速度 |
| feed_speed | 60% | 打印中补料速度（网页点动也用这个速度） |
| unload_speed | 60% | 退料速度 |
| motor_invert | 0 | 电机方向反转 |
| insert_delay_ms | 500 | 插入耗材后多久开始吸入 |
| load_timeout_s | 30 | 吸入超时 |
| first_feed_timeout_s | 120 | 开始打印后第一次送到满的超时（要走完整条 PTFE 管） |
| feed_timeout_s | 30 | 打印中每次补料的超时 |
| unload_timeout_s | 90 | 退料超时 |
| unload_extra_ms | 0 | 退料时耗材离开就绪开关后再多退的时间。太长会退出齿轮夹持范围，下次就吸不进去 |
| tail_feed_ms | 5000 | 耗材用尽（进料口开关松开）后继续送料，直到料尾过了就绪开关、离开齿轮；这是送料时间的上限，就绪开关不松开时送够这么久也停。设为 0 = 进料口一空就停 |

拓竹打印机的设置（在网页的"拓竹打印机（MQTT）"里修改）：`mqtt_enable`、`mqtt_auto_load`（响应进料，默认开）、`mqtt_auto_unload`（响应退料，默认开）、`mqtt_ip`、`mqtt_sn`、`mqtt_code`、`mqtt_unload_wait_s`（打印机退料后最多等多久再退料，默认 120 秒，0 = 马上退）。

PWM 频率、刹车时间、长按时间、配网热点名称、OTA 密码等不常改的配置在 `include/config.h`。

## 网页和无线升级

- **设备网页 `http://设备IP/`**：可以查看状态、传感器和日志，开始/结束、紧急停止、点动、调参、重启、重置配网。日志会保存到 Flash，点"查看完整日志"能看到重启前的记录（`http://设备IP/api/log`）。
- **网页升级 `/update`**：上传 `.pio/build/esp12s/firmware.bin`，用户名 `admin`，密码 `semi-ams`。
- **PlatformIO 无线升级**：设备 IP 填在 `platformio.ini` 的 `[env:ota]` 里（或加 `--upload-port IP`），然后执行 `pio run -e ota -t upload`。
- 升级过程中电机会自动停止。
- 固件按 2MB 分区编译（SEMI-AMS 板上的模组实测是 2MB），2MB 和 4MB 的模组都能无线升级。设备上还是 v1.1.x（按 4MB 编译）时 OTA 会报 `Flash config wrong`，要先用串口烧录一次 v1.2.0；第一次启动会自动把参数迁移到新分区。
- 烧录完只看串口日志时，拔掉 EN→RTS 和 GPIO0→DTR 两根线，只留 TX、RX、GND，否则设备会被按住复位或进入下载模式，网页打不开。
- 程序崩溃时，原因和调用栈会存进 RTC 内存，下次开机写进日志（"上次崩溃"几行），解码方法见文档 4.8 节。
- 改代码时注意：中文字符串都放在 Flash 里以节省内存（`LOG()`、`SEMI_P()`、`PSTR()`、`F()`），Flash 里的字符串不能直接逐字节读，写法见文档 4.10 节。
- 没有设置点灯密钥时，也可以用 `http://semi-ams.local/` 访问。设置了点灯密钥后，mDNS 由点灯库使用，请直接用 IP。

## 安全提示

- 配网热点默认不设密码，和原厂一致。热点开着的时候，范围内的人都能连上它，还能通过 WiFiManager 自带的升级页面刷固件。
- 想加密码的话，在 `include/config.h` 里把 `AP_PASSWORD` 设成至少 8 位的字符串。
- 网页升级和 OTA 的密码 `OTA_PASSWORD` 也建议改掉。

## 电脑上的仿真测试

状态机、电机控制、按键识别、拓竹打印机消息解读都是纯 C++，不需要开发板也能测试：

```bash
bash host_test/run.sh        # 加 -v 显示状态变化日志
```

覆盖的场景包括：自动吸入、就绪开关失效改用 FULL 判断、用户抽出耗材、打印补料、磁铁从 EMPTY 快速移到 FULL、各种超时、紧急停止与恢复、退料与退料中再按键继续打印、打印中耗材用尽后送出料尾、换新料、已退料后按键吸料并开始打印、就绪开关失效时的退料、上电不自动转电机、长按和短按；以及 JSON 流式解析、MQTT 报文、拓竹打印机开始打印和退料的判断。

## 需要实机确认的地方

- **编译**：MQTT 部分是新加的，还没有在真实工具链上编译过。`pio run` 如果报错，把输出发给我。
- **拓竹打印机联动**：判断规则没在 P2S 上实测，第一次使用时留意日志里"打印机…"开头的记录，把开始打印、退料时的日志发给我。
- **连接打印机的内存**：TLS 连接要占 16KB 以上的内存，日志里"连接拓竹打印机 …（空闲内存 …）"会显示连接前的空闲内存；如果提示内存不足，把这条日志发给我。
- **退料停止位置**：耗材退过就绪开关就停（`unload_extra_ms` 默认 0，可以加一点多退时间）。耗材尖端必须停在齿轮还能夹住的位置，下次才吸得进去；退多了就把这个值调小。
- **耗材用尽**：进料口开关松开后会继续送料，直到料尾过了就绪开关（离开齿轮）才停，最长送 `tail_feed_ms`（默认 5 秒）。如果料尾还卡在齿轮里，看日志是"料尾已过就绪开关"还是"料尾送料已达…"，把结果告诉我。
- **送料速度和超时**：电机实际速度未知，默认值偏保守，需要实测后调整。
- **上电时的状态**：重启后最多回到"耗材就绪"，不会自动恢复成"打印中"。打印中途断电重启后，需要再按一次黑色按钮。
- **按键**：网页状态里有"黑色按钮 / 红色按钮"两行，显示按键是否按下和引脚的实时电平（黑键 GPIO0 平时为高、按下为低；红键 GPIO15 平时为低、按下为高），日志里也会记录每一次"按下/松开"。黑色按钮没反应时先看这里：GPIO0 一直是低，多半是串口线的 DTR 拉住了它，拔掉串口线再试；电平随按键变化但没有"按下"日志，看日志里有没有"信号太短"或"定时任务被推迟"，连同串口 `status` 的输出发给我。按键按下 20ms 确认、松开 50ms 确认，快速点按也能识别。黑色按钮另外用下降沿中断锁存，触点接触不良、每次只接通零点几毫秒也能抓到；松开时日志会写出"期间触点断开又接通 N 次"，次数经常很多就该换按键了。
- **上电不自动转电机**：上电或重启时，如果进料口有耗材但没到就绪位置，会进入"已退料"，按黑色按钮才吸料。只有插入耗材这个动作才会自动吸入。
